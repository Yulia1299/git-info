# Мои заметки по Git

## Основные команды

- `git init` — инициализирует Git в папке проекта.
- `git add .` — добавляет все изменённые файлы в индекс.
- `git commit -m "Сообщение"` — сохраняет изменения с комментарием.
- `pwd` - показывает в какой папке находимся
- `cd first-project` - перейти в папку first-project
- `ls` - показывает файлы и папки в текущей папке
- `touch` - создание файла в текущей папке
- `mkdir` - создание папки в текущей папке
- `cat` - распечатай содержимое текстового файла

## Частые ошибки

- Забыть сделать `git add` перед коммитом — тогда коммит будет пустым.
- Не указать ветку при `git push` — может возникнуть путаница.
